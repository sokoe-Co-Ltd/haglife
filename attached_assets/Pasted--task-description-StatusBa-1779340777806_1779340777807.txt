## 実装する機能

### 機能1: ドラッグ中の視覚フィードバック強化

ドラッグ開始から確定まで、ドロップ先がわかりやすいUIを実装。

#### 1-1. 全体グリッドハイライト
ドラッグ開始と同時に、全スタッフ行のタイムラインに15分単位の格子線をうっすら表示。

```tsx
{isDragging && (
  <div className="absolute inset-0 pointer-events-none">
    {Array.from({ length: totalSlots }).map((_, i) => (
      <div
        key={i}
        className="absolute top-0 bottom-0 border-l border-blue-200/40"
        style={{ left: `${(i / totalSlots) * 100}%` }}
      />
    ))}
  </div>
)}
```

#### 1-2. カーソル直下セルの強調
ホバー中の15分セルを青ハイライト (over データから判定)。

#### 1-3. ゴーストブロックのプレビュー
ドラッグアイテムの所要時間分の幅を持つゴーストをカーソルに追従表示。

```tsx
{isDragging && pointerPosition && (
  <div
    className="absolute bg-blue-400/40 border-2 border-blue-600 border-dashed rounded pointer-events-none z-50 flex items-center px-1"
    style={{
      left: `${ghostLeft}%`,
      width: `${ghostWidth}%`,
      top: ghostTop,
      height: ghostHeight,
    }}
  >
    <span className="text-xs text-blue-900">
      {residentName} / {startTimePreview}-{endTimePreview}
    </span>
  </div>
)}
```

#### 1-4. 衝突警告 (赤ゴースト)
既存セルと重なる位置では、ゴーストを赤色 + 警告アイコン (⚠️) 表示。
**ドロップ自体は許可** (赤枕モード = 現状動作の維持)。

```tsx
<div className={cn(
  "absolute border-2 border-dashed rounded",
  isColliding ? "bg-red-400/30 border-red-600" : "bg-blue-400/30 border-blue-600"
)}>
  {isColliding && <span className="text-xs text-red-900">⚠️ 既存と重複</span>}
</div>
```

### 機能2: 配置済みセルの移動 (ドラッグ操作)

配置済みのガントセルを掴んで、別の時刻 or 別のスタッフ行に移動。

#### 2-1. useDraggable の適用
既存のセルレンダリングに useDraggable を追加。

```tsx
const { attributes, listeners, setNodeRef, isDragging } = useDraggable({
  id: `cell-${cell.id}`,
  data: { type: 'placed-cell', cell, sourceRowId: rowId },
});
```

#### 2-2. ドロップハンドラ分岐
- ソースが「パレット」 → 新規追加 (既存動作)
- ソースが「placed-cell」 → 既存セルの routeSheetRowId / startTime / endTime を更新

```tsx
const handleDragEnd = (event: DragEndEvent) => {
  const { active, over } = event;
  if (!over) return;

  if (active.data.current?.type === 'palette-item') {
    addCell({ ... });
  } else if (active.data.current?.type === 'placed-cell') {
    const sourceCell = active.data.current.cell;
    const targetRowId = over.data.current?.rowId;
    const targetStartTime = snapToFifteenMinutes(
      calculateStartTimeFromPosition(over.data.current?.slotIndex)
    );
    const durationMin = differenceInMinutes(sourceCell.endTime, sourceCell.startTime);
    const newEndTime = addMinutes(targetStartTime, durationMin);

    updateCell({
      cellId: sourceCell.id,
      routeSheetRowId: targetRowId,
      startTime: targetStartTime,
      endTime: newEndTime,
    });
  }
};
```

#### 2-3. 15分スナップ

```typescript
function snapToFifteenMinutes(time: string): string {
  const [h, m] = time.split(':').map(Number);
  const totalMin = h * 60 + m;
  const snapped = Math.round(totalMin / 15) * 15;
  const nh = Math.floor(snapped / 60);
  const nm = snapped % 60;
  return `${String(nh).padStart(2, '0')}:${String(nm).padStart(2, '0')}`;
}
```

#### 2-4. サーバ保存
既存の PUT /api/route-sheets/:date を使用。楽観的更新で UI 即座反映、サーバ応答で確定。

### 機能3: 配置済みセルの複製

Ctrl/Cmd キー押しながらドラッグで、元のセルが残ったまま新しい場所にコピー。

```typescript
const isDuplicateMode = event.activatorEvent instanceof KeyboardEvent
  ? event.activatorEvent.ctrlKey || event.activatorEvent.metaKey
  : (event.activatorEvent as MouseEvent)?.ctrlKey || (event.activatorEvent as MouseEvent)?.metaKey;

if (isDuplicateMode && active.data.current?.type === 'placed-cell') {
  duplicateCell({ ... });
} else if (active.data.current?.type === 'placed-cell') {
  moveCell({ ... });
}
```

タッチデバイス用には、配置済みセルを長押しした時に表示されるツールチップに「複製モードに切替」トグルボタンを追加。

```tsx
{longPressedCellId === cell.id && (
  <div className="absolute -top-8 left-0 bg-gray-800 text-white text-xs px-2 py-1 rounded shadow flex gap-2">
    <button onClick={() => setDuplicateMode(true)}>📋 複製</button>
    <button onClick={() => setMoveMode({ cellId: cell.id })}>↗ 移動</button>
    <button onClick={() => deleteCell(cell.id)}>🗑 削除</button>
  </div>
)}
```

### 機能4: タップ/クリック操作モード

#### 4-1. 動作モード

| 操作 | 動作 |
|---|---|
| シングルタップ/クリック | セル詳細パネルを開く (既存動作) |
| ダブルタップ/ダブルクリック | 移動モード開始 → セル点滅、次にタップした場所に移動 |
| 長押し (500ms以上) | ドラッグモード開始 + 操作ツールチップ表示 |

#### 4-2. 移動モード

```tsx
const [moveMode, setMoveMode] = useState<{ cellId: string } | null>(null);

const handleCellDoubleTap = (cellId: string) => {
  setMoveMode({ cellId });
};

const handleTrackTap = (rowId: string, slotIndex: number) => {
  if (moveMode) {
    const targetStartTime = calculateStartTimeFromSlot(slotIndex);
    const cell = cells.find((c) => c.id === moveMode.cellId);
    const durationMin = differenceInMinutes(cell.endTime, cell.startTime);
    moveCell({
      cellId: moveMode.cellId,
      routeSheetRowId: rowId,
      startTime: targetStartTime,
      endTime: addMinutes(targetStartTime, durationMin),
    });
    setMoveMode(null);
  }
};

<div className={cn(
  "gantt-cell",
  moveMode?.cellId === cell.id && "animate-pulse ring-2 ring-blue-500"
)}>
```

#### 4-3. 移動モード中のガイドバナー

```tsx
{moveMode && (
  <div className="fixed top-16 left-1/2 -translate-x-1/2 bg-blue-600 text-white px-4 py-2 rounded shadow-lg z-50 flex items-center gap-3">
    <span>移動先をタップしてください</span>
    <button onClick={() => setMoveMode(null)} className="underline">中止</button>
  </div>
)}

// ESCキーで中止
useEffect(() => {
  if (!moveMode) return;
  const handler = (e: KeyboardEvent) => {
    if (e.key === 'Escape') setMoveMode(null);
  };
  window.addEventListener('keydown', handler);
  return () => window.removeEventListener('keydown', handler);
}, [moveMode]);
```

#### 4-4. 長押し検知

```tsx
const longPressTimer = useRef<NodeJS.Timeout | null>(null);
const TAP_THRESHOLD_MS = 500;

const handlePointerDown = (cellId: string) => {
  longPressTimer.current = setTimeout(() => {
    setLongPressedCellId(cellId);
    if (navigator.vibrate) navigator.vibrate(50);
  }, TAP_THRESHOLD_MS);
};

const handlePointerUp = () => {
  if (longPressTimer.current) {
    clearTimeout(longPressTimer.current);
    longPressTimer.current = null;
  }
};
```

#### 4-5. ダブルタップ検知

```tsx
const lastTapTimeRef = useRef<{ [cellId: string]: number }>({});
const DOUBLE_TAP_WINDOW = 300;

const handleTap = (cellId: string) => {
  const now = Date.now();
  const lastTap = lastTapTimeRef.current[cellId] ?? 0;
  if (now - lastTap < DOUBLE_TAP_WINDOW) {
    handleCellDoubleTap(cellId);
    lastTapTimeRef.current[cellId] = 0;
  } else {
    lastTapTimeRef.current[cellId] = now;
    setTimeout(() => {
      if (lastTapTimeRef.current[cellId] === now) {
        // シングルタップ確定: 詳細パネルを開く
        openDetailPanel(cellId);
      }
    }, DOUBLE_TAP_WINDOW);
  }
};
```

## 実装注意事項

### A. 既存ロジックの保護
- 既存のパレットからの新規追加機能を壊さない
- 既存の競合検出表示 (赤枠) を維持
- 既存の PUT /api/route-sheets/:date エンドポイントを引き続き使用 (新規APIは不要)

### B. テンプレート表示モード時の挙動
source: 'template' の時、配置済みセルを移動しようとしたら確認ダイアログ:
```tsx
if (sourceData?.source === 'template' && moveOperation) {
  const choice = await showDialog({
    message: 'テンプレート表示中です。どちらを編集しますか?',
    options: ['テンプレートを編集', 'この日だけ編集', 'キャンセル'],
  });
  if (choice === 'テンプレートを編集') {
    navigateToTemplateEdit();
  } else if (choice === 'この日だけ編集') {
    await materializeFromTemplate(date);
    proceedWithMove();
  }
}
```

シンプル実装で問題ない場合は、alert で「テンプレート表示中は移動できません。先に『この日を編集する』ボタンを押してください」だけ出すのも可。

### C. パフォーマンス
- 大量セル (50件以上) でもドラッグがカクつかないよう、ドラッグ中のレンダリング最適化
- ゴーストブロック描画は requestAnimationFrame でスロットル
- 確定時のみサーバ保存 (中間状態は保存しない)

### D. アクセシビリティ
- キーボードでもセル移動: Tab でフォーカス、Space/Enter で選択、矢印キーで移動
- 移動モード中の状態は aria-live でスクリーンリーダー通知

## 動作確認シナリオ

1. **パレットからドラッグ**
   - 15分グリッドが薄く見える
   - カーソル位置に青ゴースト (所要時間幅) が追従
   - ドロップで配置完了

2. **既存セルに重なる位置にドラッグ**
   - ゴーストが赤色に + ⚠️ 表示
   - ドロップ可能 → 赤枠で配置 (競合検出)

3. **配置済みセル横ドラッグ**
   - 同じ行内で時刻が15分単位で変わる
   - ドロップで確定 → サーバ保存

4. **配置済みセル縦ドラッグ**
   - 別スタッフに担当変更

5. **Cmd/Ctrl 押しながらドラッグ**
   - 元のセルが残り、新しい場所にコピー

6. **ダブルタップ**
   - セルが点滅、移動モード開始
   - 別の場所をタップで移動
   - ESC キーで中止

7. **長押し (タッチ)**
   - ハプティックフィードバック
   - 操作ツールチップ (移動/複製/削除) 表示

8. **API 確認**
   - PUT /api/route-sheets/:date が正しく呼ばれて永続化
   - 大量操作時もデバウンス or バッチング
