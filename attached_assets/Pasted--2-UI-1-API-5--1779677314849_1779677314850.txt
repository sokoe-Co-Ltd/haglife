# 監査画面 実装指示書 / フェーズ2：監査画面UI（修正版）

## 背景

フェーズ1でデータ層（拡張カラム・監査ログ・新規API 5本＋通知採用のテンプレ重複フォールバック）が完成しました。
このフェーズではフロントエンドに `/admin/audit` を追加し、管理者が計画と実態を確認できる画面を構築します。

**設計原則**

- 既存の操作画面（ルート票編集など）には**一切手を入れない**
- 既存スタック準拠：React + Vite + TS + Wouter + TanStack Query + Tailwind + shadcn/ui + lucide-react
- Orval自動生成のReact Queryフックを使う（フェーズ1で生成済み）
- PC前提だが、Tailwindの`md:`ブレークでタブレットも閲覧可能に
- 凡例は常時表示（販売を見据えた初見ユーザー配慮）

**フェーズ1で確定した重要仕様**

- `skipReason` は null 保存。UI側で `!skipReason || skipReason.trim() === ''` で「理由未入力」を判定
- 通知採用時のレスポンスは `{ accepted, alreadyExists, fallbackScope, message, scope }` 形式。`alreadyExists=true` の場合は day_only にフォールバックされている

  return !skipReason || skipReason.trim() === '';
}

export function displaySkipReason(skipReason: string | null | undefined, fallback = '理由未入力'): string {
  return skipReason?.trim() || fallback;

```ts
// 7:00 を 0%、19:00 を 100% として時刻を百分率変換
export function timeToPercent(time: string | null | undefined, startHour = 7, endHour = 19): number {
  if (!time) return 0;
  const [h, m] = time.split(':').map(Number);
  const totalMinutes = (h - startHour) * 60 + m;
  const rangeMinutes = (endHour - startHour) * 60;
  return Math.max(0, Math.min(100, (totalMinutes / rangeMinutes) * 100));
}
```

### 3-4. セル本体（AuditGanttCell.tsx）

```tsx
import { isReasonEmpty, displaySkipReason } from '../utils/skipReason';
import { timeToPercent } from '../utils/timeToPercent';

function AuditGanttCell({ cell, axis }) {
  const [openModal, setOpenModal] = useState(false);
  
  const left = timeToPercent(cell.actualStartTime ?? cell.plannedStartTime);
  const right = timeToPercent(cell.actualEndTime ?? cell.plannedEndTime);
  const width = right - left;
  
  const colorClasses = getCellColor(cell);
  const noReason = cell.status === 'skipped' && isReasonEmpty(cell.skipReason);
  
  // 利用者軸の場合は担当ヘルパー名を表示、ヘルパー軸の場合は利用者名を表示
  const primaryLabel = axis === 'staff' ? cell.residentName : (cell.actualStaffName ?? cell.plannedStaffName ?? '未');
  
  return (
    <>
      <button
        className={cn(
          'absolute top-1.5 bottom-1.5 rounded-md p-1.5 text-xs',
          'flex flex-col justify-center overflow-hidden',
          'hover:ring-2 hover:ring-offset-1 hover:ring-foreground/20 transition',
          colorClasses
        )}
        style={{ left: `${left}%`, width: `${width}%` }}
        onClick={() => setOpenModal(true)}
      >
        <span className={cn('font-medium', cell.status === 'skipped' && 'line-through')}>
          {primaryLabel}
        </span>
        <span className="text-[10px] opacity-80">
          {cell.actualServiceLabel ?? cell.plannedServiceLabel}
          {cell.status === 'skipped' && ` ・ ${displaySkipReason(cell.skipReason)}`}
          {cell.status === 'added' && ' ・追加'}
          {cell.staffReassigned && ' ・代替'}
        </span>
        
        {/* 変更メモあり：右上に黄色ドット */}
        {cell.modifiedNote && (
          <span className="absolute top-1 right-1 size-1.5 rounded-full bg-amber-500" />
        )}
        
        {/* 追加サービス：右上にベル */}
        {cell.isAdHoc && (
          <Bell className="absolute top-1 right-1 size-2.5 text-purple-700" />
        )}
        
        {/* 理由未入力のskipped：警告アイコン */}
        {noReason && (
          <AlertTriangle className="absolute top-1 right-1 size-2.5 text-orange-600" />
        )}
      </button>
      
      <AuditCellModal cell={cell} open={openModal} onClose={() => setOpenModal(false)} />
    </>
  );
}

function getCellColor(cell): string {
  if (cell.status === 'skipped') {
    return 'bg-red-50 border border-red-500/60 text-red-900';
  }
  if (cell.isAdHoc || cell.status === 'added') {
    return 'bg-purple-50 border border-purple-500/60 text-purple-900';
  }
  if (cell.staffReassigned) {
    return 'bg-blue-50 border border-blue-500/60 text-blue-900';
  }
  return 'bg-background border border-border/60';
}
```

function NoteSection({ note, onUpdate, onDelete }) {
  const [editing, setEditing] = useState(false);
  const [text, setText] = useState(note ?? '');
  
  if (!note && !editing) {
    return (
      <button onClick={() => setEditing(true)} className="text-xs text-muted-foreground hover:underline">

      </button>
    );
  }
  
  return (
    <div className="p-3 rounded-md border bg-amber-50/40 border-amber-300">
      <div className="flex items-center justify-between mb-2">
        <span className="text-sm font-medium">変更メモ</span>
        {!editing && (
          <div className="flex gap-2">
            <button onClick={() => setEditing(true)} className="text-xs">編集</button>
            <button onClick={onDelete} className="text-xs text-red-700">消去</button>
          </div>
        )}
      </div>
      {editing ? (
        <div className="space-y-2">
          <textarea
            value={text}
            onChange={(e) => setText(e.target.value)}
            className="w-full text-sm border rounded p-2"
            rows={3}
          />
          <div className="flex gap-2 justify-end">
            <button onClick={() => { setText(note ?? ''); setEditing(false); }} className="text-xs">キャンセル</button>
            <button

              disabled={!text.trim()}
              className="text-xs bg-foreground text-background px-2 py-1 rounded disabled:opacity-50"
            >
              保存
            </button>
          </div>

### 5-2. 採用ダイアログ（AcceptDialog.tsx）

`alreadyExists=true` のフォールバック応答に対応します。

```tsx
import { toast } from 'sonner';

function AcceptDialog({ notification, date, onClose, onSuccess }) {
  const [scope, setScope] = useState<'day_only' | 'add_to_template'>('day_only');
  const accept = usePostAuditNotificationAccept();
  const weekday = new Date(date).getDay();
  const dayNames = ['日', '月', '火', '水', '木', '金', '土'];
  
  if (!notification) return null;
  
  const handleSubmit = () => {
    accept.mutate(
      {
        cellId: notification.cellId,
        data: {
          scope,
          weekday: scope === 'add_to_template' ? weekday : undefined,
        },
      },
      {
        onSuccess: (response) => {
          if (response.alreadyExists) {
            toast.warning(
              response.message ?? '既にテンプレートに存在するため、その日限りの実績として確定しました'
            );
          } else if (response.scope === 'add_to_template' || response.fallbackScope == null) {
            toast.success(
              scope === 'add_to_template'
                ? `${dayNames[weekday]}曜日のテンプレートに追加しました`
                : 'その日限りの実績として確定しました'
            );
          } else {
            toast.success('採用しました');
          }
          onSuccess();
        },
        onError: () => {
          toast.error('採用に失敗しました');
        },
      },
    );
  };
  
  return (
    <Dialog open={!!notification} onOpenChange={onClose}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>追加サービスの採用</DialogTitle>
          <DialogDescription>
            {notification.residentName} ・ {notification.actualServiceLabel} を採用します。
          </DialogDescription>
        </DialogHeader>
        
        <RadioGroup value={scope} onValueChange={(v) => setScope(v as any)}>
          <div className="flex items-start gap-2">
            <RadioGroupItem value="day_only" id="day_only" />
            <label htmlFor="day_only" className="text-sm">
              <strong>その日限り</strong>の実績として確定
              <p className="text-xs text-muted-foreground mt-0.5">
                通知から消えます。テンプレートには影響しません。
              </p>
            </label>
          </div>
          <div className="flex items-start gap-2">
            <RadioGroupItem value="add_to_template" id="template" />
            <label htmlFor="template" className="text-sm">
              <strong>{dayNames[weekday]}曜日テンプレートに追加</strong>
              <p className="text-xs text-muted-foreground mt-0.5">
                次回以降の{dayNames[weekday]}曜日にも反映されます。<br/>
                ※既に同じサービスがテンプレに存在する場合は、自動的に「その日限り」になります。
              </p>
            </label>
          </div>
        </RadioGroup>
        
        <DialogFooter>
          <button onClick={onClose} className="text-sm px-3 py-1.5 border rounded">キャンセル</button>
          <button
            onClick={handleSubmit}
            disabled={accept.isPending}
            className="text-sm px-3 py-1.5 bg-foreground text-background rounded disabled:opacity-50"
          >
            {accept.isPending ? '処理中...' : '採用する'}
          </button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

**重要**：`alreadyExists=true` のレスポンスを `toast.warning`（黄色）で表示することで、ユーザーが「テンプレ追加したつもりが day_only になった」ことに気付ける設計です。
