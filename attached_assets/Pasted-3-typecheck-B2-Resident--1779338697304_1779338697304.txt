## 修正B1: テンプレ合成 cells 埋め込み

### 該当ファイル
`artifacts/api-server/src/routes/routeSheets.ts` の合成パス (122-130行付近)

### 修正内容

現在の実装:
```typescript
const synthesizedRows = tplRowsData.map(({ row: tplRow, shiftType }) => {
  // ...
  return { sortOrder, shiftType, staffId, staffName, cells: [] };  // ← 空配列
});
```

これを、各 tplRow に対応する template cells を取得して埋め込む形に修正する。

修正方針:
1. ループ前に `routeSheetTemplateCellsTable` から、対象テンプレートの全 cells を一括取得 (N+1問題回避)
2. 取得時に `residentServiceId` で `residentServices` テーブルを JOIN して、利用者情報・サービス種別情報を取得
3. `residents.movedOutAt`, `residents.hospitalizedAt`, `residentServices.terminatedAt` でフィルタ (active のみ)
4. tplRow.id ごとに cells をグループ化したマップを作成
5. synthesizedRows の構築時に、各 row の cells に対応するセルデータを埋め込む

具体的な実装イメージ (実コードに合わせて調整すること):

```typescript
// 1. 一括取得 + JOIN
const tplRowIds = tplRowsData.map(({ row }) => row.id);
const tplCellsWithDetails = tplRowIds.length === 0 ? [] : await db
  .select({
    cell: routeSheetTemplateCellsTable,
    residentService: residentServicesTable,
    resident: residentsTable,
    serviceType: serviceTypesTable,
  })
  .from(routeSheetTemplateCellsTable)
  .leftJoin(residentServicesTable, eq(routeSheetTemplateCellsTable.residentServiceId, residentServicesTable.id))
  .leftJoin(residentsTable, eq(residentServicesTable.residentId, residentsTable.id))
  .leftJoin(serviceTypesTable, eq(residentServicesTable.serviceTypeId, serviceTypesTable.id))
  .where(inArray(routeSheetTemplateCellsTable.templateRowId, tplRowIds));

// 2. 行ごとにグループ化、active のみフィルタ
const cellsByRowId = new Map<string, any[]>();
for (const { cell, residentService, resident, serviceType } of tplCellsWithDetails) {
  // resident_service があるが、利用者が退去/入院/契約終了なら除外
  if (residentService) {
    if (resident?.movedOutAt) continue;
    if (resident?.hospitalizedAt) continue;
    if (residentService.terminatedAt) continue;
  }
  
  const cellData = {
    id: `tpl-${cell.id}`,
    routeSheetRowId: cell.templateRowId,
    startTime: cell.startTime,
    endTime: cell.endTime,
    isBreak: cell.isBreak,
    residentId: residentService?.residentId ?? null,
    residentName: resident ? `${resident.lastName} ${resident.firstName}` : null,
    serviceTypeId: residentService?.serviceTypeId ?? null,
    serviceLabel: serviceType?.shortLabel ?? null,
    notes: cell.notes,
  };
  
  if (!cellsByRowId.has(cell.templateRowId)) {
    cellsByRowId.set(cell.templateRowId, []);
  }
  cellsByRowId.get(cell.templateRowId)!.push(cellData);
}

// 3. synthesizedRows に埋め込み
const synthesizedRows = tplRowsData.map(({ row: tplRow, shiftType }) => {
  // ... 既存処理
  return {
    sortOrder: tplRow.sortOrder,
    shiftType,
    staffId,
    staffName,
    cells: cellsByRowId.get(tplRow.id) ?? [],  // ← 取得したセルを埋め込み
  };
});
```

## 修正UI3: フロント `?date=` クエリパラメータの反映

### 該当ファイル
`artifacts/home-navi/src/pages/route-sheet/index.tsx`

### 調査と修正

まず現状確認:
```bash
grep -n "date\|useSearch\|useLocation\|useParams" artifacts/home-navi/src/pages/route-sheet/index.tsx | head -30
```

Wouter は `useSearch` で query string にアクセスする。または `useLocation` で URL 全体を取得して自前パース。

修正方針:
1. Wouter の `useSearch` を import
2. URL の `?date=YYYY-MM-DD` をパースして state の初期値に使う
3. date が無ければ今日 (新規実装時のデフォルト)
4. date 変更時に URL も同期 (オプション)

実装例:
```typescript
import { useSearch } from 'wouter';
import { format } from 'date-fns';

export default function RouteSheetPage() {
  const search = useSearch();
  const searchParams = new URLSearchParams(search);
  const initialDate = searchParams.get('date') ?? format(new Date(), 'yyyy-MM-dd');
  
  const [date, setDate] = useState(initialDate);
  
  // URL 変更検知 (オプション)
  useEffect(() => {
    const params = new URLSearchParams(search);
    const urlDate = params.get('date');
    if (urlDate && urlDate !== date) {
      setDate(urlDate);
    }
  }, [search]);
  
  // ... 残りの実装
}
```
